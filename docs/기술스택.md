## 5. 상태 관리 전략

### 5.1 Context API 구조
```typescript
// DiaryContext.tsx
interface DiaryContextType {
  entries: DiaryEntry[];
  addEntry: (entry: DiaryEntry) => Promise<void>;
  updateEntry: (id: string, entry: Partial<DiaryEntry>) => Promise<void>;
  deleteEntry: (id: string) => Promise<void>;
  getEntry: (id: string) => DiaryEntry | undefined;
  getEntriesByMonth: (year: number, month: number) => DiaryEntry[];
  loading: boolean;
  error: string | null;
}
```

### 5.2 데이터 흐름
```
사용자 액션
    ↓
Screen Component
    ↓
Custom Hook (useDiary)
    ↓
Context API
    ↓
Storage Utility (AsyncStorage)
    ↓
디바이스 로컬 저장소
```

## 6. 성능 최적화

### 6.1 이미지 최적화
- **압축**: 저장 전 이미지 리사이즈 (최대 1024x1024)
- **포맷**: JPEG 품질 80%로 로컬 저장
- **캐싱**: RN 기본 Image 컴포넌트 캐싱 사용

### 6.2 리스트 렌더링
- **FlatList**: 가상화된 리스트 사용
- **getItemLayout**: 정확한 아이템 크기로 성능 향상
- **removeClippedSubviews**: 화면 밖 컴포넌트 언마운트

### 6.3 메모이제이션
```typescript
// React.memo로 불필요한 리렌더링 방지
export const DiaryCard = React.memo(({ entry }: Props) => {
  // ...
});

// useMemo로 무거운 계산 캐싱
const sortedEntries = useMemo(
  () => entries.sort((a, b) => b.date - a.date),
  [entries]
);
```

### 6.4 로컬 저장소 최적화
- **일괄 쓰기**: AsyncStorage에 한 번에 저장
- **읽기 캐싱**: 앱 시작 시 한 번만 로드, 메모리에 유지
- **크기 제한**: 이미지 압축으로 저장 공간 최소화

## 12. 보안 고려사항

### 12.1 데이터 보안
- **로컬 데이터**: iOS/Android 디바이스 자체 암호화에 의존
- **AsyncStorage**: 앱 샌드박스 내부, 다른 앱 접근 불가
- **민감 정보 없음**: 로그인 불필요, 개인 식별 정보 수집 안 함

### 12.2 이미지 보안
- 앱 샌드박스 내부에만 저장
- 외부 앱 접근 차단
- 백업 시 iOS iCloud/Android 자동 백업에 포함됨
