## 5. 상태 관리 전략

### 5.1 Context API 구조
```typescript
// DiaryContext.tsx
interface DiaryContextType {
  entries: DiaryEntry[];
  addEntry: (entry: DiaryEntry) => Promise<void>;
  updateEntry: (id: string, entry: Partial<DiaryEntry>) => Promise<void>;
  deleteEntry: (id: string) => Promise<void>;
  getEntry: (id: string) => DiaryEntry | undefined;
  getEntriesByMonth: (year: number, month: number) => DiaryEntry[];
  loading: boolean;
  error: string | null;
}
```

### 5.2 데이터 흐름
```
사용자 액션
    ↓
Screen Component
    ↓
Custom Hook (useDiary)
    ↓
Context API
    ↓
Storage Utility (AsyncStorage)
    ↓
디바이스 로컬 저장소
```

## 6. 성능 최적화

### 6.1 이미지 최적화
- **압축**: 업로드 전 이미지 리사이즈 (최대 1024x1024)
- **캐싱**: react-native-fast-image로 메모리 캐싱
- **포맷**: JPEG 품질 80%로 저장

### 6.2 리스트 렌더링
- **FlatList**: 가상화된 리스트 사용
- **getItemLayout**: 정확한 아이템 크기로 성능 향상
- **removeClippedSubviews**: 화면 밖 컴포넌트 언마운트

### 6.3 메모이제이션
```typescript
// React.memo로 불필요한 리렌더링 방지
export const DiaryCard = React.memo(({ entry }: Props) => {
  // ...
});

// useMemo로 무거운 계산 캐싱
const sortedEntries = useMemo(
  () => entries.sort((a, b) => b.date - a.date),
  [entries]
);
```

## 8. 빌드 및 배포

### 8.1 iOS
```bash
# 개발 빌드
npx react-native run-ios

# 릴리스 빌드
cd ios && xcodebuild -workspace DrawDiary.xcworkspace \
  -scheme DrawDiary -configuration Release
```

### 8.2 Android
```bash
# 개발 빌드
npx react-native run-android

# 릴리스 APK
cd android && ./gradlew assembleRelease
```
