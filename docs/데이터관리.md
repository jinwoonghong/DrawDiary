# DrawDiary 데이터 관리 가이드

## 개요

DrawDiary는 **100% 로컬 저장소**를 사용하는 앱입니다. 모든 데이터는 사용자의 디바이스에만 저장되며, 별도 서버로 전송되지 않습니다.

## 1. 데이터 저장 방식

### 1.1 저장 위치
- **일기 데이터**: AsyncStorage (앱 샌드박스)
- **이미지 파일**: 디바이스 로컬 파일 시스템 (앱 전용 디렉토리)

### 1.2 데이터 구조

```javascript
// AsyncStorage Key: "diary_entries"
[
  {
    id: "1698123456789",           // 타임스탬프 기반 고유 ID
    date: "2025-10-21",            // 일기 날짜 (YYYY-MM-DD)
    mood: "😊",                    // 감정 이모지
    text: "오늘은 정말 좋은 날...", // 일기 텍스트 (최대 150자)
    imageUri: "file:///path/to/image.jpg", // 이미지 로컬 경로
    imageType: "photo",            // 'photo' | 'sketch'
    createdAt: 1698123456789,      // 생성 타임스탬프
    updatedAt: 1698123456789       // 수정 타임스탬프
  }
]
```

### 1.3 파일 경로 구조
```
앱 샌드박스/
├── AsyncStorage/
│   └── diary_entries (JSON)
└── Documents/
    └── DrawDiary/
        └── images/
            ├── 1698123456789.jpg  (사진)
            └── 1698123456790.png  (스케치)
```

## 2. 자동 백업

### 2.1 iOS (iCloud)
- **자동 활성화**: 사용자가 iCloud 백업을 켜놓은 경우 자동으로 백업됨
- **백업 범위**: AsyncStorage 데이터 + 이미지 파일
- **복원**: 새 기기에서 iCloud 복원 시 자동으로 일기 데이터 복원

### 2.2 Android (Google Drive)
- **자동 활성화**: 사용자가 Google 백업을 켜놓은 경우 자동으로 백업됨
- **백업 범위**: AsyncStorage 데이터 + 이미지 파일
- **복원**: 새 기기에서 Google 복원 시 자동으로 일기 데이터 복원

### 2.3 주의사항
- 자동 백업은 OS 설정에 의존
- 사용자가 백업을 비활성화한 경우 백업되지 않음
- 따라서 수동 백업 기능도 제공 필요

## 3. 수동 백업 (내보내기/가져오기)

### 3.1 데이터 내보내기

#### 기능
- 모든 일기를 JSON 파일로 내보내기
- 이미지 포함 ZIP 파일 생성 (선택사항)

#### 내보내기 형식

**옵션 1: JSON만 (텍스트 데이터)**
```json
{
  "version": "1.0",
  "exportDate": "2025-10-21T12:34:56Z",
  "entries": [
    {
      "id": "1698123456789",
      "date": "2025-10-21",
      "mood": "😊",
      "text": "오늘은 정말 좋은 날...",
      "imageUri": "1698123456789.jpg",
      "imageType": "photo",
      "createdAt": 1698123456789,
      "updatedAt": 1698123456789
    }
  ]
}
```

**옵션 2: ZIP (JSON + 이미지)**
```
DrawDiary_Backup_20251021.zip
├── data.json
└── images/
    ├── 1698123456789.jpg
    └── 1698123456790.png
```

#### 저장 위치
- iOS: Files 앱에 저장 → 사용자가 iCloud Drive, Dropbox 등에 복사 가능
- Android: Downloads 폴더 또는 공유 메뉴로 이메일, 드라이브 등에 직접 전송

### 3.2 데이터 가져오기

#### 기능
- 내보낸 JSON 또는 ZIP 파일에서 일기 복원
- 기존 일기와 병합 또는 덮어쓰기 선택

#### 가져오기 옵션
1. **병합**: 기존 일기 유지 + 새 일기 추가
   - ID가 같은 경우: 최신 날짜 기준으로 유지
2. **덮어쓰기**: 기존 일기 삭제 + 새 일기로 교체
   - 주의: 복구 불가능

#### UI 플로우
```
설정 → 데이터 가져오기 → 파일 선택
→ 미리보기 (몇 개의 일기가 복원되는지)
→ 병합/덮어쓰기 선택 → 확인
→ 가져오기 완료
```

## 4. 데이터 보안

### 4.1 암호화
- **디바이스 수준**: iOS/Android 디바이스 자체 암호화 의존
- **앱 수준**: 별도 암호화 없음 (MVP)
- **향후**: 사용자가 패스코드 설정 시 추가 암호화 고려

### 4.2 개인정보 보호
- **수집하지 않는 정보**:
  - 이름, 이메일 등 개인 식별 정보
  - 위치 정보
  - 연락처
  - 사용자 행동 분석 데이터
- **완전 오프라인**: 서버로 데이터 전송 없음

### 4.3 앱 삭제 시
- **주의**: 앱 삭제 시 모든 데이터 영구 삭제
- **권장**: 앱 삭제 전 반드시 데이터 내보내기 수행

## 5. 저장 공간 관리

### 5.1 용량 계산
- **일기 1개 (텍스트만)**: 약 0.5KB
- **일기 1개 (이미지 포함)**: 약 100~500KB
- **1년치 일기 (365개, 이미지 50% 포함)**: 약 50~100MB

### 5.2 최적화
- **이미지 압축**: 업로드 시 자동 압축 (1024x1024, JPEG 80%)
- **자동 정리**: 없음 (사용자가 직접 삭제)

### 5.3 용량 초과 시
- **경고**: 디바이스 저장 공간 부족 시 OS 경고
- **대응**:
  1. 오래된 일기 삭제
  2. 데이터 내보내기 후 삭제
  3. 이미지 없는 일기 작성

## 6. 데이터 마이그레이션

### 6.1 기기 변경 시

#### 방법 1: OS 자동 백업 (권장)
1. 이전 기기에서 iCloud/Google 백업 활성화
2. 새 기기에서 백업 복원
3. DrawDiary 설치
4. 자동으로 데이터 복원 확인

#### 방법 2: 수동 백업
1. 이전 기기에서 데이터 내보내기 (ZIP)
2. iCloud Drive, Google Drive 등에 업로드
3. 새 기기에서 파일 다운로드
4. DrawDiary에서 데이터 가져오기

### 6.2 Android → iOS 또는 iOS → Android
- **OS 자동 백업 불가**: 플랫폼 간 백업 공유 안 됨
- **해결**: 수동 백업 사용 (ZIP 파일)

## 8. FAQ

### Q1. 서버에 저장되나요?
**A**: 아니요. 모든 데이터는 100% 디바이스에만 저장됩니다.

### Q2. 앱을 삭제하면 일기가 사라지나요?
**A**: 네. 반드시 삭제 전에 데이터를 내보내기 하세요.

### Q3. 다른 기기와 동기화되나요?
**A**: 아니요. 각 기기에서 독립적으로 작동합니다. 수동 백업으로 이동 가능합니다.

### Q4. iCloud/Google 백업이 자동으로 되나요?
**A**: 사용자가 OS 설정에서 백업을 활성화한 경우 자동으로 됩니다.

### Q5. 일기가 몇 개까지 저장 가능한가요?
**A**: 디바이스 저장 공간이 허용하는 한 무제한입니다. 보통 수천 개 이상 가능합니다.
