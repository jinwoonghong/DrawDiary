# DrawDiary 실제 테스트 가이드

## 🚀 빠른 시작

### Android (권장 - 더 빠름)

**1단계: Android Studio 준비**
```bash
# Android Studio가 설치되어 있는지 확인
# https://developer.android.com/studio
```

**2단계: 에뮬레이터 시작**
- Android Studio 실행
- Tools → AVD Manager
- 에뮬레이터 선택 (Pixel 4 이상, API 33+ 권장)
- ▶️ 버튼 클릭하여 실행

**3단계: 앱 실행**
```bash
# 프로젝트 디렉토리에서
npm install
npm run android

# 또는 Metro 서버를 별도로 시작
npm start
# 새 터미널에서
npm run android
```

**예상 결과**: 에뮬레이터에서 DrawDiary 앱이 자동으로 실행됩니다.

---

### iOS (Mac만 가능)

**1단계: Xcode 준비**
```bash
# Xcode가 설치되어 있는지 확인
xcode-select --install
```

**2단계: CocoaPods 설치**
```bash
# CocoaPods 설치 (한 번만)
sudo gem install cocoapods

# Pod 설치
cd ios
pod install
cd ..
```

**3단계: 앱 실행**
```bash
npm install
npm run ios

# 특정 시뮬레이터 선택
npm run ios -- --simulator="iPhone 15"
```

**예상 결과**: iOS 시뮬레이터에서 DrawDiary 앱이 자동으로 실행됩니다.

## 📱 테스트 시나리오

### 1. 온보딩 (첫 실행)
- [ ] 앱을 처음 실행하면 온보딩 화면이 표시됨
- [ ] 4개의 슬라이드를 넘기며 확인
- [ ] "시작하기" 버튼을 눌러 메인 화면으로 이동
- [ ] 다시 실행해도 온보딩이 표시되지 않음

### 2. 일기 작성
- [ ] 오른쪽 하단 **+** 버튼 클릭
- [ ] 5가지 감정 중 하나 선택 (😊 😢 😡 😴 😎)
- [ ] 텍스트 입력 (예: "오늘은 정말 좋은 날이었다!")
- [ ] 남은 글자 수 확인 (150자 제한)
- [ ] **사진 또는 스케치 추가** 버튼 클릭

#### 옵션 A: 카메라 (실제 기기만)
- [ ] 카메라 권한 허용
- [ ] 사진 촬영
- [ ] 미리보기 확인

#### 옵션 B: 갤러리
- [ ] 갤러리 권한 허용
- [ ] 사진 선택
- [ ] 미리보기 확인

#### 옵션 C: 스케치 ✨
- [ ] 스케치 화면 표시
- [ ] 화면에 손가락으로 그림 그리기
- [ ] "실행 취소" 버튼으로 마지막 동작 되돌리기
- [ ] "전체 지우기" 버튼으로 모두 지우기
- [ ] 다시 그린 후 "완료" 버튼 클릭
- [ ] 일기 작성 화면에 "✏️ 스케치" 표시 확인

- [ ] 헤더 오른쪽 **저장** 버튼 클릭
- [ ] 홈 화면으로 자동 복귀

### 3. 캘린더 뷰
- [ ] 작성한 날짜에 점(dot) 표시 확인
- [ ] 작성한 날짜 클릭 → 상세 화면 이동
- [ ] 작성하지 않은 날짜 클릭 → 새 일기 작성 화면

### 4. 타임라인 뷰
- [ ] 탭에서 "타임라인" 선택
- [ ] 일기 카드에 날짜, 감정, 텍스트 미리보기 표시
- [ ] 카드 클릭 → 상세 화면 이동

### 5. 검색 기능 🔍
- [ ] 헤더 오른쪽 🔍 버튼 클릭
- [ ] 검색창에 텍스트 입력 (예: "좋은")
- [ ] 실시간으로 검색 결과 표시
- [ ] ✕ 버튼으로 검색어 지우기
- [ ] 다시 🔍 버튼으로 검색 모드 종료

### 6. 일기 상세 보기
- [ ] 큰 감정 이모지 표시
- [ ] 날짜 표시 (예: "2025년 10월 21일")
- [ ] 전체 텍스트 표시
- [ ] 이미지 전체 크기로 표시
- [ ] 이미지 타입 표시 (📷 사진 또는 ✏️ 스케치)
- [ ] 작성일/수정일 메타 정보

### 7. 일기 수정
- [ ] 상세 화면에서 "수정" 버튼 클릭
- [ ] 감정, 텍스트, 이미지 수정
- [ ] 저장 → 변경사항 반영 확인

### 8. 일기 삭제
- [ ] 상세 화면에서 "삭제" 버튼 클릭
- [ ] 확인 다이얼로그 표시

## 🐛 문제 해결

### Metro 연결 오류
```bash
# 캐시 삭제
npm start -- --reset-cache

# node_modules 재설치
rm -rf node_modules package-lock.json
npm install
```

### Android 빌드 실패
```bash
# Gradle 캐시 삭제
cd android
./gradlew clean
cd ..

# 재빌드
npm run android
```

### iOS 빌드 실패 (Mac)
```bash
# Pod 재설치
cd ios
rm -rf Pods Podfile.lock
pod install --repo-update
cd ..

# 재빌드
npm run ios
```

### 권한 오류 (카메라/갤러리)
- Android: 설정 → 앱 → DrawDiary → 권한 → 카메라, 파일 접근 허용
- iOS: 설정 → DrawDiary → 카메라, 사진 허용

### 스케치가 작동하지 않음
- react-native-signature-canvas가 WebView를 사용하므로 시간이 조금 걸릴 수 있음
- 에뮬레이터에서는 마우스로, 실제 기기에서는 손가락으로 그리기

### 앱이 시작되지 않음
```bash
# Metro 서버 수동 시작
npm start

# 새 터미널에서
npm run android
# 또는
npm run ios
```

## 💡 팁

### 빠른 테스트
- **Reload**: Android (R키 2번), iOS (Cmd+R)
- **개발자 메뉴**: Android (Cmd+M 또는 Ctrl+M), iOS (Cmd+D)

- **Fast Refresh**: 코드 변경 시 자동 리로드

- **Element Inspector**: UI 요소 검사

### 로그 확인
```bash

npx react-native log-android

# iOS 로그 (Mac)
```
