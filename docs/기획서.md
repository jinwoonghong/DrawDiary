# DrawDiary - 그림일기 모바일 앱 기획서

## 1. 프로젝트 개요

### 1.1 서비스 컨셉
- **서비스명**: DrawDiary (그림일기)
- **핵심 가치**: 하루를 2~3문장의 짧은 글과 그림으로 간단하게 기록하는 일기 앱
- **타겟 사용자**:
  - 일기를 쓰고 싶지만 긴 글쓰기가 부담스러운 사람
  - 시각적 기록을 선호하는 사람
  - 매일의 소소한 순간을 기록하고 싶은 사람

### 1.2 핵심 차별점
- **간결함**: 2~3문장으로 제한하여 부담 없이 매일 작성 가능
- **시각적 표현**: 그림을 통해 감성적으로 하루를 표현
- **심플한 UX**: 애플 디자인 시스템 기반의 직관적이고 아름다운 인터페이스

## 2. 핵심 기능 (MVP 범위)

### 2.1 일기 작성
- **텍스트 입력**: 2~3문장 분량의 일기 작성 (글자 수 제한: 150자)
- **그림 추가**:
  - 옵션 1: 사진 촬영/갤러리에서 선택
  - 옵션 2: 간단한 스케치 기능 (기본 브러시, 색상 선택)
- **날짜 자동 기록**: 작성 시점의 날짜 자동 저장
- **감정 태그**: 오늘의 기분을 이모지로 선택 (😊 😢 😡 😴 😎)

### 2.2 일기 조회
- **캘린더 뷰**: 월간 캘린더에서 일기 작성된 날짜 확인
- **타임라인 뷰**: 시간 순서대로 일기 목록 조회
- **상세 보기**: 작성한 일기 내용 및 그림 확인

### 2.3 기본 관리
- **수정**: 작성한 일기 수정
- **삭제**: 작성한 일기 삭제
- **검색**: 텍스트 기반 일기 검색

### 2.4 데이터 관리 (로컬 전용)
- **자동 백업**: iOS iCloud/Android 자동 백업에 의존
- **데이터 내보내기**: JSON 파일로 모든 일기 내보내기
- **데이터 가져오기**: 내보낸 파일에서 일기 복원

## 3. 사용자 플로우

### 3.1 첫 실행 (온보딩)
```
앱 실행 → 환영 화면 → 사용법 안내 (3페이지) → 메인 화면
```

### 3.2 일기 작성 플로우
```
메인 화면 → [+] 버튼 클릭 → 일기 작성 화면
→ 감정 선택 → 텍스트 입력 → 그림 추가 (선택사항)
→ [저장] 버튼 → 메인 화면 (작성 완료 토스트)
```

### 3.3 일기 조회 플로우
```
메인 화면 → 캘린더/타임라인 전환
→ 일기 선택 → 상세 보기 → [수정]/[삭제]
```

## 4. 기술 스택 (MVP 최적화)

### 4.1 프론트엔드 (모바일)
- **프레임워크**: React Native
  - 이유: iOS/Android 동시 개발, 빠른 개발 속도
- **상태 관리**: React Context API + Hooks
  - 이유: 최소한의 의존성, 기본 기능으로 충분
- **네비게이션**: React Navigation
- **로컬 저장소**: AsyncStorage
  - 이유: 간단한 key-value 저장소, 별도 DB 설정 불필요
  - 모든 데이터는 디바이스에만 저장 (서버 없음)

### 4.2 필수 라이브러리 (최소화)
- **캘린더**: react-native-calendars
- **그림 그리기**: react-native-sketch-canvas
- **이미지 선택**: react-native-image-picker
- **기본 UI**: React Native 내장 컴포넌트 (Paper 제거하여 최소화)

## 6. 데이터 모델

### 6.1 DiaryEntry
```javascript
{
  id: string,              // UUID
  date: timestamp,         // 작성 날짜
  mood: string,            // 감정 이모지
  text: string,            // 일기 텍스트 (max 150자)
  imageUri: string,        // 이미지 로컬 경로 (선택)
  imageType: 'photo' | 'sketch', // 이미지 타입
  createdAt: timestamp,
  updatedAt: timestamp
}
```

## 8. MVP 이후 확장 계획 (Phase 2)

> **중요**: 모든 기능은 로컬 디바이스에서만 작동하며, 별도 서버를 사용하지 않습니다.

### 8.1 향상된 일기 기능
- 추가 감정 태그 및 카테고리
- 더 많은 스케치 도구 (브러시 종류, 두께, 투명도)
- 스티커 및 데코레이션
- 음성 메모 첨부

### 8.2 시각화 및 통계
- 월간/연간 감정 분석 차트
- 작성 빈도 통계
- 가장 많이 사용한 단어 분석
- 연간 하이라이트 자동 생성

### 8.3 개인화
- 다크 모드 / 라이트 모드
- 커스텀 테마 색상
- 폰트 크기 조정
- 위젯 지원 (홈 화면에 최근 일기 표시)

### 8.4 향상된 백업
- 이메일로 백업 파일 전송
- PDF로 일기 내보내기
- 이미지 포함 ZIP 파일 생성
