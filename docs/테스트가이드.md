# DrawDiary 테스트 가이드

## 사전 준비

### Android 테스트
1. **Android Studio 설치 확인**
   ```bash
   # Android SDK 경로 확인
   echo $ANDROID_HOME
   ```

2. **에뮬레이터 시작** (Android Studio에서)
   - AVD Manager 열기
   - 에뮬레이터 실행 (API 33 이상 권장)

3. **또는 실제 기기 연결**
   - USB 디버깅 활성화
   - 기기 연결 확인: `adb devices`

### iOS 테스트 (Mac만 가능)
1. **Xcode 설치**
2. **CocoaPods 설치**
   ```bash
   sudo gem install cocoapods
   ```

3. **Pod 설치**
   ```bash
   cd ios
   pod install
   cd ..
   ```

## 앱 실행

### 방법 1: npm 스크립트
```bash
# Android
npm run android

# iOS (Mac만)
npm run ios
```

### 방법 2: Metro + 수동 빌드
```bash
# Terminal 1: Metro 서버 시작
npm start

# Terminal 2: 빌드 및 실행
# Android
npx react-native run-android

# iOS (Mac만)
npx react-native run-ios
```

## 알려진 이슈 (해결 필요)

### Android
1. **카메라 권한**
   - 첫 실행 시 권한 요청 표시 확인
   - 권한 거부 시 적절한 안내 메시지

2. **이미지 선택**
   - Android 13+ (API 33)에서 READ_MEDIA_IMAGES 권한 필요
   - 이전 버전에서는 READ_EXTERNAL_STORAGE 사용

### iOS
1. **Info.plist 설정 필요**
   - NSCameraUsageDescription
   - NSPhotoLibraryUsageDescription
   - NSPhotoLibraryAddUsageDescription

## 문제 해결

### Metro 에러
```bash
# 캐시 삭제
npm start -- --reset-cache
```

### Android 빌드 에러
```bash
# Gradle 캐시 삭제
cd android
./gradlew clean
cd ..

# 재빌드
npm run android
```

### iOS 빌드 에러 (Mac)
```bash
# Pod 재설치
cd ios
rm -rf Pods Podfile.lock
pod install
cd ..

# 재빌드
npm run ios
```
